# 📱 Install APK dengan Sideloadly
**Tanggal:** September 16, 2026  
**Tujuan:** Install APK ke Android device via Sideloadly

---

## 📋 Prerequisites:

```
✅ APK file downloaded (app-release-*.apk)
✅ Sideloadly installed (https://sideloadly.io)
✅ Android device atau emulator (Android 5.0+)
✅ USB cable untuk connect device
```

---

## 🔧 STEP 1: Setup Android Device

### 1A. Enable USB Debugging

**Di Android Phone Settings:**

```
Settings → About Phone → Build Number
  ↓ Tap 7x sampai "Developer mode enabled"
  ↓
Settings → Developer Options → USB Debugging
  ↓ Toggle ON ✓
```

### 1B. Connect ke PC via USB

```
1. Plug USB cable ke Android phone
2. Plug cable ke PC
3. Tunggu 2-3 detik untuk recognize
4. Di phone: Tap "Allow" jika ada popup "Allow USB debugging?"
```

### 1C. Verify Connection

```
Di PC:
- Check Settings → Devices → Android phone muncul
- Atau di Sideloadly: Device dropdown harus show phone
```

---

## 🔄 STEP 2: Install APK dengan Sideloadly

### 2A. Buka Sideloadly

```
Windows Start Menu → Sideloadly
Atau double-click Sideloadly.exe
```

### 2B. Select Device

```
Top area, dropdown: "Select Device"
Pilih Android phone Anda
Status: Device connected
```

### 2C. Select APK File

```
Middle area, button: "Select App" atau "..."
Atau: Drag-drop APK file ke window

File browser terbuka:
- Navigate ke: Downloads folder
- Pilih: app-release-*.apk
- Click "Open"
```

### 2D. Verify APK Info

```
Sideloadly menampilkan:
- App name: Tongkrongan
- App icon: Logo Tongkrongan
- Version: 1.0.0 atau similar
- Size: ~60 MB
```

### 2E. Click "Install"

```
Large button: "Install" (warna blue/hijau)
Click tombol tersebut
```

### 2F. Monitor Installation

```
Progress bar muncul:
- Uploading: 0% → 100%
- Installing: 0% → 100%
- Verifying: ✓

Estimated time: 2-5 menit
```

### 2G. Installation Complete

```
Status muncul: "✓ Installation Completed"
Atau: "Installation Successful"

APK sekarang sudah installed di phone
```

## ⚠️ TROUBLESHOOTING:

### Problem: Device not muncul di Sideloadly

```
Solusi:
1. Buka Settings → Developer Options → USB Debugging → ON
2. Disconnect USB → wait 3 detik → reconnect
3. Di phone: Tap "Allow" jika ada popup
4. Close Sideloadly → Reopen
5. Jika masih tidak muncul: Restart phone
```

### Problem: Installation Failed / Error

```
Solusi:
1. Uninstall app manual:
   Settings → Apps → Tongkrongan → Uninstall
2. Retry installation di Sideloadly
3. Jika masih gagal: Restart phone & PC
```

### Problem: App Crashes saat dibuka

```
Solusi:
1. Tap "Allow" jika ada permission popup
2. Force close: Settings → Apps → Tongkrongan → Force Stop
3. Reopen app
4. Jika crash lagi:
   - Uninstall & reinstall
   - Check phone logs (logcat)
```

### Problem: Installation Stuck

```
Solusi:
1. Wait 5-10 menit (sometimes slow)
2. Restart Sideloadly
3. Reconnect USB
4. Retry installation
```
