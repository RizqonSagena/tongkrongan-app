## 🚨 Common Issues & Solutions

### App won't build?
```bash
flutter clean
flutter pub get
flutter run
```

### Images not loading?
- Check internet connection
- Images from Unsplash should be accessible
- App shows loading spinner then error icon

### Animations not smooth?
- Use `--profile` mode: `flutter run --profile`
- Close other apps
- Check FPS in DevTools

### Keyboard covers inputs?
- This is normal mobile behavior
- App handles scrolling
- Form buttons remain accessible
